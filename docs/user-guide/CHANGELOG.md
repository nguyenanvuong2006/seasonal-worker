# Changelog — Tài liệu hướng dẫn sử dụng

Ghi lại lịch sử cập nhật của **tài liệu** (không phải lịch sử cập nhật hệ thống). Cập nhật file này mỗi khi giao diện/nghiệp vụ thay đổi đủ nhiều để ảnh hưởng tới nội dung hướng dẫn.

## 1.0 — 12/08/2026

- Phát hành bộ tài liệu hướng dẫn sử dụng đầy đủ đầu tiên.
- Dựa trên mã nguồn nhánh `main` tại thời điểm viết (sau khi PR *Professional UI/UX redesign* đã được merge).
- Ảnh chụp màn hình dùng dữ liệu demo tạo riêng cho tài liệu (không phải dữ liệu lao động thật).
- Bao gồm: Quick Start, 23 chương nội dung, 3 cheat sheet theo vai trò, bản HTML in được ra PDF.

---

**Ghi chú bảo trì:** Ảnh chụp màn hình trong tài liệu này có thể lệch nhẹ so với giao diện thật sau các bản cập nhật UI sau này (*"Screenshots may change slightly after UI updates"*) — nếu phát hiện sai lệch, cập nhật lại ảnh và mô tả tương ứng, tăng số phiên bản tài liệu ở đầu file này.

**Người phụ trách tài liệu (Maintainer):** cập nhật theo phân công nội bộ — hiện chưa có tên cụ thể.

**Phiên bản mã nguồn tương ứng khi viết tài liệu 1.0:** nhánh `main`, sau commit merge *Professional UI/UX redesign* (`9eef8a6` trở lên).
